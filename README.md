# mySilversat_admin

لوحة تحكم خدمة **سلفرسات** للبث الفضائي — واجهة إدارية بالعربية (RTL) مبنية على React + TypeScript + Vite.

الواجهة **بدون باك-إند حقيقي**: كل شاشة تقرأ من طبقة بيانات وهمية قابلة للاستبدال بـ API لاحقاً دون تعديل أي مكوّن — التبديل يتم في ملف واحد (`src/data/repositories/index.ts`).

## التشغيل

```bash
npm install
npm run dev        # http://localhost:5180
npm run build      # فحص الأنواع + بناء الإنتاج
npm run typecheck  # فحص الأنواع فقط
```

اللوحة بحساب واحد فقط: `admin` — أي كلمة مرور من 4 أحرف فما فوق تُقبل. ما بيها أدوار ولا صلاحيات، كل الشاشات مفتوحة.

## الشاشات

- **عام** — لوحة المعلومات
- **توقع واربح** — المباريات، التوقعات، الترتيب والنقاط، الدوريات والفرق
- **المشتركون** — المشتركون، الأجهزة، التجديدات، الباقات والأسعار، الوكلاء
- **السحوبات** — السحوبات والجوائز، الكوبونات
- **محتوى التطبيق** — العروض، سلايدر الرئيسية، الفيديوهات، الأسئلة الشائعة، الأبراج
- **التواصل** — الإشعارات
- **النظام** — المحافظات، سجل العمليات، الإعدادات
