# mySilversat_admin

لوحة تحكم خدمة **سلفرسات** للبث الفضائي — واجهة إدارية بالعربية (RTL) مبنية على React + TypeScript + Vite.

الواجهة **بدون باك-إند حقيقي**: كل شاشة تقرأ من طبقة بيانات وهمية قابلة للاستبدال بـ API لاحقاً دون تعديل أي مكوّن — التبديل يتم في ملف واحد (`src/data/repositories/index.ts`).

## التشغيل

```bash
npm install
npm run dev        # http://localhost:5180
npm run build      # فحص الأنواع + بناء الإنتاج
npm run typecheck  # فحص الأنواع فقط
```

اللوحة بحساب واحد فقط: `admin` — أي كلمة مرور من 4 أحرف فما فوق تُقبل. ما بيها أدوار ولا صلاحيات، كل الشاشات مفتوحة.

## الشاشات

- **عام** — لوحة المعلومات
- **توقع واربح** — المباريات، التوقعات، الترتيب والنقاط، الدوريات والفرق
- **المشتركون** — المشتركون، الأجهزة، التجديدات، الباقات والأسعار، مخزن الكارتات، الوكلاء
- **السحوبات** — السحوبات والجوائز، الكوبونات
- **محتوى التطبيق** — العروض، سلايدر الرئيسية، الفيديوهات، الأسئلة الشائعة، الأبراج
- **التواصل** — الإشعارات
- **النظام** — المحافظات، الـ API، سجل العمليات، الإعدادات

## ثلاث قواعد تحكم اللوحة

### المباريات تجي من API — ما تنضاف يدوياً

الدوريات والفرق والمباريات كلها مرآة لمزوّد خارجي. ما بيها زر «إضافة مباراة» ولا «إضافة فريق»، بس
زر **مزامنة**. الربط يصير على `externalId` تبع المزوّد، فالمزامنة الثانية تحدّث ما تكرّر.

اللي تملكه اللوحة فوق بيانات المزوّد هو قرار التوقع فقط — أي مباراة تنفتح للتوقع، متى يقفل، وهل
تنثبّت على الرئيسية — والمزامنة ما تلمس هذي الحقول أبداً. الاستثناء الوحيد **تصحيح النتيجة يدوياً**:
النقاط تنحسب على النتيجة، فإذا المزوّد غلط تكدر تثبّت نتيجة صحيحة، وتنعلّم المباراة حتى المزامنة
الجاية ما ترجّعها. إعدادات المزوّد (الدومين والمفتاح وفترة المزامنة) في شاشة **الإعدادات**.

### كل محافظة إلها مخزن كارتات

المخزن **لكل محافظة** لأن هيك يشتغل فعلاً: التجديد بالبصرة يحرق كارت بصرة. التجديد يسحب أقدم كارت
متاح (FIFO) بنفس مدة الباقة من مخزن محافظة المشترك، وإذا خلص المخزون **التجديد ينرفض** بدل ما يمدّد
اشتراك ما دفع عليه كارت. المنحة المجانية هي الطريقة الوحيدة اللي ما تسحب كارت.

الاسترجاع ما يرجّع الكارت للرف — الكارت انفعّل عند المزوّد فعلاً — فينعلّم «ملغى» ويظل بالسجل.

### كل محافظة إلها API

كل المحافظات تشتغل على نفس البرنامج، يتغيّر بس **الدومين وAuth Key واسم المستخدم والرمز**. شاشة
**الـ API** تضيف السيرفر مرة وحدة وبعدها تربط عليه المحافظات. القاعدة المفروضة: **المحافظة تنربط
بسيرفر واحد بس** — اختيارها على سيرفر ثاني ينقلها، ما يزدوجها.
